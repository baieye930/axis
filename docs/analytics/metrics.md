# 2. 지표 정의

공통: 분석 동의(`analytics`)한 사용자만 포함. 건강 지표는 `health` 동의자만. 계정 연결 화면은 `personal` 동의자만.
표본이 5명 미만이면 집계를 보여주지 않는다(`MIN_USERS`). 사용자 평균에는 기간 내 기록일이 3일 이상인 사용자만 포함(`MIN_USER_DAYS`).

| 지표 | 정의 |
|---|---|
| 기록일 | 실제 값(기상·취침·완료·건너뜀 중 하나)이 있는 날. **계획만 있는 날·미래 날짜·사용 시작 이전은 포함하지 않음** |
| 가입/활동/기록 사용자 | 기간 내 가입 / 최근 활동일이 기간 이후 / 기록일이 있는 사용자 |
| D7 유지율 | 첫 기록일 +7~+13일 안에 다시 기록한 사용자 ÷ 첫 기록일로부터 13일이 지난 사용자 |
| 평균 기상·취침 | 사용자별 원형 평균 → 사용자 간 원형 평균. 23:30과 00:30의 평균은 00:00. 집중도 R<0.5면 "분산 큼" 경고 |
| 평균 수면 시간 | 건강 동의자의 `sleepH` 사용자별 평균 → 사용자 평균 |
| 루틴 완료율(기본) | 하루 완료율 = 완료 ÷ (대상 − 건너뜀). 사용자별 평균 → 사용자 평균 |
| 완료 항목 비율(가중) | 기간 전체 완료 수 ÷ 대상 수(사용자 합산). 기본 지표와 다르다는 점을 화면에 표시 |
| 기록 누락률 | 사용 시작 이후 기간 내 날짜 중 기록일이 아닌 날의 비율 |
| 계획 시간 이동 비율 | 계획 루틴 중 시간이 조정된 것 ÷ 전체 계획 루틴. 제외·직접 지정은 별도 표시 |
| 충돌 제안 수락 비율 | 수락 ÷ (수락+취소). 수락·취소·표시 건수를 함께 표시 |
| 운동/식사 기록 | 건강 동의자의 사용자-일 기준 평균(회·세트·kcal·단백질) |
| 일별 추이 | 그날 기록한 사용자가 5명 이상인 날만 표시 |

상관·비교는 "관찰된 경향"이며 원인이나 의학적 판단이 아니다. 화면에도 같은 문구를 둔다.
