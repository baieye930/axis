# 4. 동의 화면·개인정보 안내 문구 초안

문구의 원본은 `index.html`의 `AN_ITEMS`이며 아래는 요약이다. **법적 적합성은 주장하지 않으며 법률 검토가 필요하다.**

- 모든 체크박스(전체 동의 포함)는 기본 미선택. 선택 항목은 서비스·분석·개인별·건강으로 분리.
- 분석은 개인별·건강의 전제. 필수(서비스)에 동의하지 않으면 "동의하지 않고 나가기" 또는 게스트 사용 가능.
- 선택 항목을 거부해도 기본 기능은 그대로 사용.
- 각 항목에 수집 내용·목적·거부 시 영향을 표시. 설정 > 개인정보에서 항목별 변경·분석 전체 철회·내 분석 데이터 삭제.
- 운영 주체·문의처·저장 지역·처리 서비스·보존 기간은 `config.js` 값을 화면에 표시한다(비어 있으면 화면 자체가 나오지 않음).

## 법률 검토 때 확인할 것
건강 관련 정보의 별도 동의 요건 해당 여부, 국외 이전·처리위탁 고지, 만 14세 미만 처리, 보존 기간 근거, 철회 후 로그 보관 범위, 동의 문서 버전 관리 방식.
